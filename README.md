# Rosa Blu

Gioco di ruolo a turni in Java con interfaccia JavaFX. Il giocatore è un
barista: serve clienti, guadagna soldi, migliora le sue statistiche e
sblocca nuove abilità giorno dopo giorno.

Progetto individuale per l'esame di Metodologie di Programmazione e
Modellazione della Conoscenza (A.A. 2025/2026), Università di Camerino.

## Requisiti

- Java 25 
- Nessuna installazione di Gradle: usa il wrapper incluso

## Come eseguire

    ./gradlew build
    ./gradlew run

Su Windows usa `gradlew.bat` al posto di `./gradlew`.
